# Podcast App
A personal podcast aggregator and player designed for seamless multi-device continuity. This application serves as a self-hosted alternative to commercial podcast platforms, focusing on the ability to switch between devices while maintaining playback progress.
## Overview
The primary goal is to provide a unified listening experience where a user can start a podcast on one device and resume immediately from the same point on another. The application uses server-side rendering (SSR) to deliver a consistent player interface across different web-capable devices.
The system is designed to automate the management of podcast feeds by fetching metadata and episode information from external sources once a URL is provided.
### Features (some TODO)
* Seamless Playback Sync: Track and synchronize playback state across all active sessions and devices.
* Podcast Search: Discover new podcasts directly within the application.
* Metadata Enrichment: Automatic extraction of titles, artwork, and episode lists from RSS feeds.
* SSR Web Interface: A lightweight, fast web-based player.
