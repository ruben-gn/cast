# Android "Linen Paper" theme — design

**Date:** 2026-06-06
**Status:** implemented
**Scope:** Android app only (webapp restyle is a deliberate later follow-up)

## Problem

The Android app used Material You **dynamic color** (`dynamicLightColorScheme`/`dynamicDarkColorScheme`).
The user's wallpaper is pure black, so the derived palette was near-grayscale with an
essentially random accent (the "green" play button). There was no intentional brand identity.

## Decision

Replace dynamic color with a fixed, deliberate brand theme: **Linen Paper** — a warm,
light, ink-on-paper look with a sienna-red accent. Chosen via an iterative browser
brainstorm (light paper beat teal/amber/indigo/emerald/crimson directions).

### Palette

| Role | Hex |
|------|-----|
| primary / accent | `#D8512A` (sienna) |
| onPrimary | `#FFFFFF` |
| background (page) | `#FBF8F3` (near-white linen) |
| surface (cards/sheets/bars) | `#FFFFFF` |
| onBackground / onSurface (ink) | `#2B241E` |
| onSurfaceVariant (muted) | `#8E8175` |
| surfaceVariant (track) | `#ECE5DB` |
| outline | `#DBD0C0` |
| primaryContainer | `#FBE0D6` |
| onPrimaryContainer | `#4A1A0C` |

### Key choices (confirmed with user)

- **Light only.** `CastTheme` ignores the system dark-mode setting and always applies the
  linen scheme. No dark theme, no in-app toggle. (The `darkTheme` param is kept but unused so
  callers/previews don't break.)
- **Paper grain on the page background only.** Surfaces stay clean white so text contrast is
  never affected.
- **Update widget + launcher icon now** so the brand is consistent (they were teal/navy).

## Components

1. **`ui/theme/Color.kt`** (new) — palette constants, incl. a warm neutral `surfaceContainer*`
   ramp and `outlineVariant`/`tertiary`/inverse roles, so Material3 components
   (`NavigationBar`, elevated surfaces, menus) don't fall back to Material's cool-gray/purple
   defaults and fight the linen.
2. **`ui/theme/Theme.kt`** — single static `lightColorScheme`; `CastTheme` always light.
3. **`ui/theme/PaperBackground.kt`** (new) — fills the screen with the linen color and a
   seamlessly-tiled grain overlay (`ShaderBrush` + `ImageShader(TileMode.Repeated)`), hosts
   content on top. Draw alpha `GrainAlpha = 0.55f`.
4. **`res/drawable-nodpi/paper_grain.png`** — 160×160 seamless salt-and-pepper grain,
   generated by `scripts/gen_paper_grain.py` (tile 3×3 → blur → centre-crop so it wraps).
5. **`MainActivity`** — wrap app in `PaperBackground`; `Scaffold` `containerColor =
   Color.Transparent` so grain shows through; `enableEdgeToEdge` forced to
   `SystemBarStyle.light` (dark bar icons) since the app is always light.
6. **`res/values/themes.xml`** — `windowBackground = @color/linen_background` (no launch flash).
7. **`res/values/colors.xml`** — `ic_launcher_background` navy `#1A1A2E` → sienna `#D8512A`;
   added `linen_background`.
8. **Widget** (`NowPlayingWidget.kt` + `drawable/widget_background.xml`) — ink/muted text,
   sienna accent, warm paper gradient background.

## Open / follow-up

- **Grain opacity needs on-device tuning.** `GrainAlpha` (and/or the PNG's baked `MAX_ALPHA`)
  was set on a browser preview; it must be checked on a real phone panel. The user builds on a
  Mac off git, so this is a tuning pass after the first install.
- **Contrast:** white-on-sienna is ~4:1 — fine for the play glyph and large text, marginal for
  very small labels. `onPrimary` is not used for small body text in current screens.
- **Webapp restyle** to match Linen Paper — explicitly deferred.
